# Flipkart Web Scraper 📱

A Python script that scrapes mobile data (name, price, rating, and image) from Flipkart using BeautifulSoup.

### 🧰 Tools Used
- Python
- BeautifulSoup
- Requests
- Pandas

### 🚀 Features
✅ Multi-page scraping  
✅ CSV export  
✅ Handles missing data  
✅ Easy to modify for other websites

### 💡 Learning Journey
This is my first working web scraping project! I learned how to handle pagination, loops, and extract real data using Python.
